# VIP FOV + Weapon — final test/fix

Модуль заменяет обычный `VIP_FOV` и использует одну VIP-фичу:

```text
"FOV" "90,100,110,120,130,150"
```

## ВАЖНО ПЕРЕД УСТАНОВКОЙ

На сервере должен быть загружен **только один** FOV-модуль.

Удалите/переместите из папки плагинов:

- старый оригинальный `VIP_FOV`;
- предыдущие тестовые `vip_fovweapon.so`;
- предыдущие `vip_viewmodelfov.so`;
- любые копии этого модуля под другим именем.

Оставьте только свежий:

```text
vip_viewmodelfov.so
```

Если загружены две версии, они могут одновременно ловить одну команду/событие и перезаписывать FOV друг другу. Это объясняет ситуации вроде `!fovcam 120`, после которых позднее снова появляется `150`.

## Что исправлено

1. `m_iDesiredFOV` и `CameraServices::m_iFOV/m_iFOVStart` теперь имеют **один общий target** на игрока.
2. `!fovcam`, `!fovweapon` и VIP-меню используют один и тот же код и больше не должны спорить со старым cookie.
3. При выборе FOV у VIP cookie обновляется сразу. Поэтому `!fovcam 120` не должен после spawn вернуться к старому `150`.
4. После `weapon_switch` / `item_equip` FOV и viewmodel XYZ восстанавливаются несколько кадров подряд.
5. `m_flViewmodelFOV` оставлен только для диагностики: текущий клиент CS2 принимает значение, но визуально его игнорирует.
6. Реальное серверное отдаление оружия делается через `m_flViewmodelOffsetX/Y/Z`, которые ваш клиент уже подтвердил как рабочие.

## Автоматическое отдаление оружия

По умолчанию используются такие значения:

```text
FOV 90  -> XYZ 2.50 / 2.00 / -2.00
FOV 120 -> XYZ 2.50 / 5.60 / -2.60
FOV 150 -> XYZ 2.50 / 9.20 / -3.20
```

Для промежуточных FOV значения рассчитываются плавно.

Это не клиентский `viewmodel_fov`: сервер физически отодвигает viewmodel, потому что именно XYZ клиент реально принимает с сервера.

## Команды

Применить FOV + автоматическое отдаление оружия:

```text
!fovweapon 120
```

То же самое через CameraServices-алиас:

```text
!fovcam 120
```

Ручная настройка оружия, которая сохраняется при переключении оружия:

```text
!fovoffset 2.5 7.0 -2.8
```

Вернуть автоматический расчёт XYZ:

```text
!fovauto
```

Диагностика:

```text
!fovdiag
```

После `!fovweapon 120` ожидается примерно:

```text
world=120 cam=120/120
vmXYZ=2.50 5.60 -2.60 target=120 auto=yes
```

## Первый тест

1. Удалить все старые FOV `.so` и оставить только новый `vip_viewmodelfov.so`.
2. Перезапустить сервер полностью.
3. В игре выполнить:

```text
!fovweapon 120
!fovdiag
```

4. Переключить нож -> пистолет -> автомат -> нож.
5. Снова:

```text
!fovdiag
```

Должно остаться `world=120`, `cam=120/120`, а XYZ должны оставаться около `2.50 5.60 -2.60`.

Если оружие хочется ещё дальше, не пересобирая модуль:

```text
!fovoffset 2.5 8 -3
```

или

```text
!fovoffset 2.5 10 -3
```

Когда подходящее положение найдено, `!fovauto` возвращает автоматический режим.
