# VIP_FOVWeapon safe client command test

Эта версия НЕ создаёт `point_clientcommand` и НЕ вызывает `DispatchSpawn`.
Это сделано специально после серверного SIGSEGV при старте предыдущей версии.

Клиентские команды отправляются напрямую через официальный интерфейс HL2SDK:

`IVEngineServer2::ClientCommand(CPlayerSlot, ...)`

## Тест

1. Удали предыдущую `vip_viewmodelfov.so` и поставь только новую.
2. Запусти сервер. Он не должен падать при загрузке модуля.
3. В игре проверь:

```
!clientvm 54
!clientvm 68
!clientfov 120
!fovexact 120
!fovdiag
```

Важно: `ClientCommand` не гарантирует выполнение любого клиентского cvar. Engine разрешает удалённое выполнение только допустимых клиентских команд. Поэтому главный первый тест этой версии — отсутствие краша. Если `fov_cs_debug` будет заблокирован, дальше нужен другой клиентский путь; возвращаться к `point_clientcommand` через текущий `DispatchSpawn` не следует.
